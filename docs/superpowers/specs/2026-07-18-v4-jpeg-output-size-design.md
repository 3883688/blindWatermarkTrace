# V4 JPEG 水印输出体积设计

## 背景

当前水印服务将所有处理结果固定保存为 PNG。JPEG 照片经过隐式水印处理后包含较多高频像素变化，PNG 对这类数据压缩效率很低。实际样本从 1.18 MB 的 JPEG 增长为 11.97 MB 的 PNG，约为原文件的 10.13 倍。

## 目标

- JPEG 原图使用 V4 水印时，输出仍为 JPEG。
- JPEG 输出保持原文件的色度采样方式，避免将常见的 4:2:0 照片无谓提升为体积更大的 4:4:4。
- 在 JPEG 质量不低于 90 的前提下，尽量将输出控制在上传原文件大小的 1.25 倍以内。
- 体积目标与质量下限冲突时，优先保证 JPEG 质量不低于 90 和 V4 水印可检测性。
- PNG、WebP 等非 JPEG 输入及 V1-V3 旧版水印继续使用无损 PNG 输出，避免破坏 LSB 水印层。
- 保持现有下载、缩略图、文件指纹、像素指纹、特征索引和追溯流程可用。

## 非目标

- 不保证每张 JPEG 水印图均小于原文件的 1.25 倍。
- 不对旧版 V1-V3 水印输出 JPEG，因为 JPEG 有损编码无法保证 LSB 数据完整。
- 不改变水印强度、V4 载荷、检测阈值或前端表单。
- 不重新编码或迁移历史水印文件。

## 方案选择

采用按输入格式和水印版本自适应保存的方案：

1. 通过解码所得的真实图片格式识别 JPEG，不依赖文件名或请求 Content-Type。
2. 仅当输入为 JPEG 且水印版本为 V4 时启用 JPEG 输出。
3. JPEG 输出保持源文件可识别的 4:4:4、4:2:2 或 4:2:0 色度采样；无法识别时回退到 4:4:4。
4. 其他情况沿用现有 PNG 输出，维持旧版功能和透明通道兼容性。

未采用固定质量 90 的方案，因为部分图片可在更高质量下满足体积目标。未采用继续优化 PNG 的方案，因为带高频水印的照片数据无法通过 PNG 参数调整稳定达到目标体积。

## JPEG 编码策略

- 输出扩展名为 `.jpg`，编码格式为 JPEG。
- 使用优化编码和渐进式编码，并保持源 JPEG 的色度采样方式。采样读取只接受 Pillow 明确定义的 4:4:4、4:2:2 和 4:2:0 值；其他返回值使用 4:4:4 安全回退。
- 以上传文件的字节数为体积基准，目标上限为原文件的 1.25 倍。
- 在质量 95 至 90 的闭区间内选择不超过目标上限的最高质量。
- 若质量 90 仍超过目标上限，则保存质量 90 的结果，不再降低质量。
- 编码选择在内存中完成，最终结果只写入一次正式输出路径，避免残留候选文件。

## 数据流与一致性

水印嵌入过程保持不变。完成 V4 嵌入后，保存层根据原始格式和水印版本选择 JPEG 或 PNG，并返回实际持久化后的图片。

服务在任何图像变换前，从已解码的原 JPEG 读取色度采样方式。该值通过现有的可注入水印操作边界传给保存层，不依赖文件扩展名或请求 Content-Type，也不改变 V4 水印载荷、强度和检测阈值。

JPEG 是有损格式，持久化后的像素与编码前像素不同。因此缩略图、V4 特征索引、水印图像素指纹及其他依赖最终图像内容的计算，必须使用重新解码后的正式输出文件。文件 MD5 和 SHA-256 继续直接基于正式输出文件计算。这样数据库记录、下载文件与后续追溯输入保持一致。

原图保存、原图 URL、记录字段语义及精确文件指纹流程保持不变。`download_url` 根据实际输出格式使用 `.jpg` 或 `.png` 后缀，现有静态文件服务据此返回正确媒体类型。

## 错误处理

- 无法识别或解码的上传仍返回现有的 400 错误。
- JPEG 编码失败时不静默降级为不同格式，沿用服务错误处理，避免记录指向不完整文件。
- 质量 90 超出体积目标不视为错误，这是明确的质量优先策略。
- 只有正式输出保存成功后，才生成依赖文件并写入数据库记录。

## 测试策略

- 先增加失败测试，证明当前 JPEG+V4 路径错误地输出 PNG 且体积显著膨胀。
- 验证 JPEG+V4 输出扩展名和实际文件格式均为 JPEG，编码质量选择范围为 90-95。
- 分别用 4:4:4、4:2:2 和 4:2:0 JPEG 输入验证输出保持源采样；未知采样验证回退为 4:4:4。
- 使用可稳定压缩的 JPEG 样本验证：存在合适质量时，输出不超过原文件的 1.25 倍。
- 使用高度压缩的 JPEG 样本验证：质量 90 仍超限时保留质量下限，不因体积目标继续降质。
- 将生成的 JPEG 水印图重新上传，验证精确文件指纹追溯和 V4 解码追溯成功。
- 验证 PNG+V4 仍输出 PNG。
- 验证 JPEG+V1-V3 仍输出 PNG，并保留 LSB 提取能力。
- 运行现有后端测试套件，确认下载 URL、缩略图、指纹、特征索引和历史接口契约没有回归。

## 验收标准

- JPEG+V4 不再固定转为 PNG。
- JPEG 输出质量始终不低于 90。
- 在质量 90-95 范围内可满足时，输出体积不超过上传原文件的 1.25 倍。
- 无法同时满足时，输出质量 90，且 V4 水印仍能从输出文件中检测。
- JPEG 输出保持可识别的源色度采样；未知采样使用 4:4:4。
- 非 JPEG 输入和旧版水印行为保持不变。
- 所有新增测试及相关现有测试通过。
